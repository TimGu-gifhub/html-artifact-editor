# 方案 B 产品工作台

日期：2026-09-10。维护者已选择 HAE-007 方案 B，并授权实施实时草稿预览、逐条/全选复核、隐藏/拆卸校稿栏和 PDF 打印预览。本合同替代产品设计中需要点击“应用”才看见效果的默认流程；底层 Apply 仍是经过验证的草稿提交原语。

## 交互合同

- 输入后约 250 毫秒短暂停顿自动更新草稿和预览；连续输入串行提交，只保留最新待发输入。中文组词期间只保留输入，组词结束后更新。每次确认的自动更新形成可撤销记录，保存 HTML 仍须明确点击。
- 界面区分“正在输入/正在更新预览”“草稿已预览”“已写入 HTML”和恢复记录的持久化状态。迟到的结果不能覆盖较新的本地输入，也不能投递给另一文档或文字。
- 映射失效或关闭时，仍将已绑定或待处理输入展示为可选择、可复制的只读文本；保留文本不解除编辑保护，也不表示恢复或保存成功。
- 失焦、隐藏、拆卸、PDF、保存和文件切换须先排空输入；组词或失败时保留编辑区域和文本。Escape 只取消尚未预览的输入；已预览内容通过“还原本段”或撤销恢复，还原本段形成可撤销草稿，不冒充零历史取消。上述动作均不自动写 HTML。
- 原生关闭先向当前输入窗口请求排空；组词、断连或失败拒绝本次关闭，不重放旧保存。浮窗关闭按钮收回校稿栏；不关闭文档。主窗口仍拥有文档、文件权限及退出决定。
- “更多操作 → 切换目录内 HTML…”复用 Main 当前目录授权。动作开始固定当前文档，排空实际输入窗口后使用最新修订；文档变化、组合态、失败或忙碌时不打开选择器。取消选择、越界或拒绝离开保留草稿；另存/放弃仍须原有 Main 决定，新文档不继承旧输入或复核。
- 工具栏及“更多操作”可切换脚本只读预览与静态校稿。当前模式同时显示在主窗口、浮窗和状态栏；只读期间没有输入/复核绑定，编辑、保存、备份替换与新草稿 PDF 停用，已有 PDF 仍标为先前快照。切换先固定文档并排空输入，Main 决定旧草稿的取消/放弃/另存；干净历史经重新验证保留，源文件冲突拒绝旧历史迁移。详见 [模式合同](MODE_SWITCH.md)。
- 静态校稿可通过工具栏或“更多操作 → 显示隐藏内容”临时展开包含受支持文字的预置 `hidden` 内容。先排空实际输入窗口，再以最新修订请求 Main；不执行页面脚本、不改变源属性、文字历史、已有复核或打印规则。打开/恢复的新文档使用默认显隐；模式切换和核验后的保存可保留已验证的单一面板。Main 核验实际显示与样式撤回，无法确认时不自动重试；范围见 [隐藏静态内容](HIDDEN_CONTENT.md) 和 [就地校稿](CONTEXTUAL_EDIT.md)。
- “更多操作 → 恢复草稿记录…”可选择 HTML 文件或项目目录。每次新开默认文件方式，以 HTML 所在文件夹为资源根；目录方式先明确选择根目录，再选择其中的入口，适用于上级共享资源。取消或失败保留本次选项，不自动改用单文件或推断旧目录授权；Main 继续验证文件身份、hash 和恢复点。
- 点击恢复后，先同步锁住本次操作与对话框关闭，再排空实际输入窗口；固定记录、来源方式及可空文档身份，排空后只向同一文档发送最新修订。重复点击和竞争快捷键不会再打开选择器。取消、失败或连接异常后解除忙碌并保留选项；只有明确 restored 结果关闭原对话框。记录读取与操作结果绑定本次窗口，关闭、重开或卸载后的迟到结果不得覆盖新窗口。
- 勾选表示已复核当前条目的原文/新文。再次修改该条，取消其复核标记；其他未改变条目保留。全选只作用于当前全部净变更。保存要求全部当前变更已复核，并绑定最新 Diff 版本；不提供部分勾选保存。
- 方案 B 保留宽校稿栏与下方复核清单。隐藏后预览占满可用空间；独立浮窗可拖动、调整尺寸、重新停靠。页面始终在无 Node、文件和广域 IPC 的隔离原生视图中。
- 正常入口默认原位输入：点击 Text 后自动在原位置输入，复核可从工具栏直接打开并全选，无需收回侧栏。校稿栏、完整浮窗和附近小窗仍为可选载体。当前输入归属在 inline 时为原位窗，在 contextual/floating 时为旧编辑窗口，在 docked/hidden 时为主窗口；组词和几何变化保留同一 textarea/token，覆盖层先排空实际 owner。精确 Text 边框由单独无输入权限的原生装饰窗绘制，不修改用户 DOM，不进入 PDF 或源文件。完整支持范围与生命周期见 [就地校稿合同](CONTEXTUAL_EDIT.md)。
- 浏览后校稿可通过整树证明保留有限渐显、展开问答和预置提交提示；状态标记仅描述已核验的显示差异。partial 明确提示返回浏览定位，不能声称保存了框架状态。输入、历史、打印与源码边界见 [当前显示补充](CURRENT_VIEW.md)。
- PDF 从当前已确认草稿生成，生成时冻结该文档的输入，提供 A4/Letter、横向、背景选项。打印预览显示这次生成的 PDF；导出复用同一份字节。明确标注包含未保存草稿。导出不保存 HTML；目标通过原生对话框选择，首版独占创建新 PDF，已有文件要求换名。

## 前端交接

“更多操作 → 检查上次中断”提供重启后的完整保存事务与检查点清理核验、单独原生确认及结果提示。当前有文档时只显示说明，不自动关闭或放弃。检查过程、原生关闭与界面丢失均等待同一次 Main 处理；未知结果/警告保留证据并禁止直接重试。完整合同见 [产品中断检查](INTERRUPTION_WORKFLOW.md)。

允许 Kimi 修改 `src/ui/**` 和新增 `tests/product/ui-*.mjs`；不得修改 contracts、preload、Main、platform、core、依赖或构建。视觉依据为 `docs/design/hae-007/` 的方案 B。主代理提供 [Workspace API](../src/contracts/workspace-editor.ts)、[输入状态](../src/contracts/input.ts)、[桌面 API](../src/contracts/desktop.ts) 并负责集成和独立验证。

`window.haeWorkspace` 维持已有 API，`window.haeDesktop.request` 仅在正式产品窗口暴露。桌面状态随 `WorkspaceSnapshot.desktop` 发布，独立 revision 不替代文档 stateRevision。role 区分主窗口/编辑浮窗/原位窗口；panel 决定当前输入控件归属。原生 Preview 的 bounds 必须由主窗口中实际占位元素计算，菜单/抽屉/模态打开时明确隐藏原生 Preview，关闭时恢复同一视图及滚动位置；不能用 CSS 假设可以遮盖原生视图。

`flush` 是 Main 绑定当前输入窗口的单次关闭/停靠请求。UI 排空输入后仅对该 id 返回 flushed；组词或失败返回 ready=false。复核在 Main 保存，跨停靠/浮窗保持。PDF 在单独受限的本地 PDF 窗口显示，桌面状态仅包含名称、版本和大小，不暴露私有路径或原始字节。

中断检查任务的前端交接另允许 Kimi 编写 `src/main/product/interruption-copy.ts` 的纯文案函数；仅 type import 和字符串格式化，不能包含平台调用、授权、回调或文件操作。原生按钮的默认取消、源选择、决定绑定与事务均由主代理负责。其余 Main 禁写规则继续适用。

就地校稿任务在 2026-09-11 重新核对模型并保持同一 CLI/模型/设置；Kimi 负责限定 UI、装饰 Canvas 和前端测试，唯一 Main 例外为 `presentation-style.ts` 的纯展示 CSS 字符串函数。该函数不读取页面或文件、不执行 IO、不作授权决定，外层屏幕媒体和验证由 Main 集成控制。
