# 浏览与原位校稿

2026-09-11。方案 B 的正常入口默认使用原位输入。点击页面中受支持的文字，就在该位置输入并实时预览；侧栏、独立浮窗和附近小窗仍是可选载体。应用只编辑纯文字，不提供字号、加粗、结构编辑或 AI 服务。

## 操作

1. 打开 HTML。需要切换标签页时先选“浏览”，使用页面原有交互到达目标正文。
2. 选择“编辑文字”。经核验的预置正文和滚动位置继续显示，页面脚本停止，源码映射重新建立。
3. 点击原文字，在同一位置直接输入。字体、颜色和行高按所选 Text 的显示信息匹配；点击位置给出初始光标，后续输入和预览更新不重置光标。约 250 毫秒停顿后更新草稿，不需要点击应用。
4. 点工具栏“复核变更”，逐项或全选确认，再检查源码 Diff 并保存。各窗口宽度均可直接打开复核，无需先收回侧栏。

Esc 取消尚未预览的输入，已预览内容可用主窗口撤销。失焦只排空当前输入，不结束会话、不写 HTML。打开菜单、复核、PDF 等覆盖层，以及切换模式、输入载体或关闭窗口前，排空实际输入 owner；组词、失败或未确认输入不得悄悄丢弃。

文字滚出视区、变为空或暂时不能取得几何信息时，同一输入元素保留在标注“文字已离开视区 · 输入已保留”的临时面板内；恢复几何后回到原位置。组合输入期间不移动窗口、不卸载输入、不改变布局，待组词结束再处理最新位置。首次选中但几何不受支持的文字可使用校稿栏；不伪造原位成功。

## 展示状态与源码证明

- Main 从 SourceIndex 识别同父级、连续同标签、唯一非空 ID 的面板组，至少两块，每块包含受支持静态 Text。范围为 `pre/div/section/article/aside/main/p`，注释和空白不打断元素连续性。可支持 `hidden` 或 CSS 类/样式控制的面板，不要求特定类名或 ARIA。
- 最多 100 块面板、5000 个子树节点、256 KiB 序列化字符预算；超限整体放弃展示延续并报告 partial。Main 生成数字路径，不接受页面或 UI 提交的路径或选择器。
- 私有隔离 world 按完整子树核验节点类型、父子关系、名称、命名空间、全部 Text/注释及属性。只允许面板根的 `hidden/class/style/aria-hidden` 与源码不同；后代文字、结构和其他属性必须一致。每组只接受一块实际可见正文，携带有界的实际 display 类型。脚本生成、删除、改写的正文整组跳过，不迁移 DOM 或文字。
- 核验后的组使用可撤回 author-origin `@media screen` 样式控制显示，并检查随机标记及每块真实显隐。可识别的 `role=tablist` 子按钮通过精确 `aria-controls` 或 `data-tab` 与面板 ID 后缀关联，选中标签有临时下划线/字重强调；所有这些信息都不是 Text 写入权限。
- 切换沿用 Main 接受的视口，尽量对齐当前视口内已验证面板的位置，否则保留文档滚动坐标。读取和显示核验各限 5 秒，原有源版本、离开决定和原生安装检查仍强制执行。未知显示结果不能声称成功。
- 保存提交并核验之后，使用新源码再次核对旧视图，延续当前面板与滚动位置；显示延续失败只能报告 partial，不能把已经核验的 SaveCommit 变成需要重新保存的失败。新文件版本和新映射仍需在安装前后通过检查。
- 返回浏览时先以临时屏幕样式保留当前面板。第一次被 Main 接受的可信鼠标/键盘交互撤回该样式，让页面原脚本继续切换；合成事件不授予撤回权限。Main 合并同一撤回操作，后续切换和销毁等待它，未知结果保留证据且不盲目重复撤回。

上述为相邻面板合同；后续整树证明增加了渐显、CSS 显隐、已展开问答和本地提交提示，见 [当前显示补充](CURRENT_VIEW.md)。`DesktopState.presentation` 仅公开当前 documentId、保留组数 panels、可选显示元素数 elements/问答数 details 和 restored/partial；没有源码范围、原始子树或 offset。只读模式没有 mapping、draft、writer、input 或 persistence；返回编辑须重建静态源码证明。展示状态不进入检查点：重新打开或恢复仍从文件原规则开始。“显示隐藏内容”继续作为批量展开支持区域的可选入口，撤回当前面板样式后才展开；精确边界见 [隐藏静态内容](HIDDEN_CONTENT.md)。

## 原位输入与边框

- 隔离 preload 复用节点注册表的对象证明，仅对当前悬停/选中的最多两个 Text 读取 Range。每种最多 80 个矩形，裁切至视口与矩形 overflow 边界；不扫描整页重建节点，不修改 DOM 属性或 contenteditable。
- 原位几何同时携带有限字体、纯色背景、行高、文字方向、缩进及点击光标提示。复杂 transform、mask、clip-path、渐变/图像背景、文字变换等不宣称原位匹配。样式由可信 UI 逐项赋值，不能携带源码或脚本。几何、光标和路径都不授权选字或写盘。
- 16 毫秒合并刷新，有目标时每 100 毫秒只重查这些范围；重复数据不发送。Main 核验 sender/frame/session、映射身份/修订、递增序号、已知 Text ID、当前选择以及视口/缩放。旧位置不能赋给新选中的文字；点击激活只属于该 Text。
- 原位输入是 Main 创建的透明、无标题栏、无阴影原生子窗口，覆盖已核验的 Text 位置。它复用 LiveInputController 和现有 begin/change/apply/resolve。正常入口使用 `panel=inline`、`role=inline`；侧栏/隐藏的 owner 是主窗口，floating/contextual 的 owner 是旧编辑窗口，每次只有一个实际输入 owner。Main 工厂的测试默认仍可使用 docked，正常启动明确选择 inline。
- `InlineTextPlacement.detached` 由 Main 决定，仅改变同一输入的显示方式；Preview 不能请求该字段。组词期间保留位置，几何恢复与窗口大小变化不重建 textarea 或转移 token。失败输入保持可查看/复制；输入错误不变成源文件写入。
- 精确边框由另外的透明、不可聚焦、鼠标穿透原生窗绘制。其 preload 仅接收 `haeDecoration`，没有 Workspace/Desktop/Editor API。装饰窗和原位窗均登记为应用拥有的辅助窗口，关闭等待准备、已接受工作和清理。

## 打印与验证边界

面板样式只作用于屏幕，PDF 使用原 HTML 打印规则，可能只显示文件默认标签。原位输入、侧栏和边框不是用户文档，不进入保存或 PDF。本阶段不增加打印全部标签或自动修复版式。

任意 CSS 状态、内部滚动容器状态、脚本生成/重构正文、框架状态和复杂变换不保证延续；问答和渐显的有限支持见当前显示补充。只保证能重新对应源码的静态 Text；原位显示不可用时仍可使用校稿栏。

`npm run test:product-inline` 使用真实产品窗口、原生输入、生产 IPC/Workers 和 Windows Save，分别运行 hidden 属性和无 ARIA 的 CSS 类标签两种样例。覆盖直接点击/光标/字体位置、组词时菜单及关闭拒绝、空值/多行/Esc、同一元素的滚动回退、缩放、全选复核/Diff、保存后面板、可信交互恢复页面切换和动态内容拒绝。旧工作台、显隐和模式切换另做回归。文件选择与确认由 Main 测试回调提供；合成组合事件不替代真实 Windows IME，OS 鼠标、多屏 DPI、Windows 10 和 M2 人工校稿仍需单独验收。执行记录见 [HAE-009](implementation/HAE-009.md)。
