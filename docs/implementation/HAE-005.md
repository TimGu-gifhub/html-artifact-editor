# HAE-005 最小校稿闭环阶段记录

日期：2026-09-09。任务：[Issue #5](https://github.com/TimGu-gifhub/html-artifact-editor/issues/5)。本阶段验证基线：`7b0517c579b24d5de792748cc9b7dfd5720240db` 加本次差异；最终提交见 Issue。**任务仍进行中**，本记录覆盖后台合同与自动实验，尚无供用户操作的校稿技术 UI。

## 本阶段行为

真实原生点击选择标题/表格 Text 后，Main 从当前草稿取得旧值，在可取消 worker 中重建和验证基线、净 Patch 与完整新候选，再请求隔离 registry 同步核对并修改 Text.data。确认成功才发布新草稿；不写原 HTML。取消另存不写文件；显式另存可独占创建同目录新 HTML，校验完成后在新会话重开。

正常 `npm run dev` 和 `npm run preview` 入口仍是已有只读验证壳。当前由 `npm run test:draft` 驱动 Main API；未应用输入、IME、焦点、用户对话框和产品按钮均未接入，不能把自动调用当作用户完整校稿或 M1/M2 验收。

## 接口与一致性

| 部件 | 合同 |
| --- | --- |
| [DraftApply](../../src/contracts/draft.ts) | selection、draftRevision、newText 三字段；不接受路径、offset、旧值或任意操作名 |
| [Main DraftSession](../../src/main/draft/session.ts) | idle/preparing/applying/saving/uncertain/closed；准备/应用/另存期间拒绝第二个命令；冻结请求，防止异步后调用者改值 |
| [后台准备](../../src/main/draft/prepare.ts) | 五秒期限、可取消、V8 堆限制；等待 worker 真正终止后返回；恢复净 Patch 必须重新通过核心验证和当前 resultHash |
| [隔离 registry](../../src/preview/node-registry.ts) | 当前 generation/revision、选中 ID、Text 对象、连接状态、旧值和伪元素约束共同验证；同步赋值，没有观察器断开窗口 |
| [Main 确认](../../src/main/preview/source-mapping.ts) | 精确 sender/session/main frame/URL、身份、requestId、旧 revision 和新 revision；两秒无确认进入未知状态 |
| [新文件平台适配器](../../src/platform/new-file.ts) | 只允许 Main 授权目录的直接 HTML 兄弟文件；拒绝跨目录、UNC、设备/ADS、隐藏名和别名；O_EXCL 永不截断已有文件 |

赋值后只接受唯一的目标 characterData 记录，随后更新登记值；空串保留同一个 Text 对象以便续写。无变化不产生新净 Patch 或草稿 revision，但仍使旧选择 revision 过期。同节点改回基线保留原实体字节。外部即使赋相同值，仍使映射失效。

确认丢失时保留已知候选和待确认候选，拒绝编辑/另存盲目重试；关闭服务也不清除这些对象。当前仅保留内存证据，崩溃持久化与恢复界面仍待 HAE-010，不能宣称可恢复。

另存期间冻结当前候选和命令入口，取消选择器保持原草稿；成功后仍保留原入口基线和未保存变更，不把副本创建误称为原文件已保存。适配器在独占创建后保持同一句柄，写入、sync、回读 SHA-256，前后核对目录链及文件身份、大小、时间和链接数。创建之前失败返回 failed，之后任何异常返回 unknown；不自动删除部分文件、替换文件或证据。
