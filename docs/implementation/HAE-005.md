# HAE-005 最小校稿闭环阶段记录

日期：2026-09-09。任务：[Issue #5](https://github.com/TimGu-gifhub/html-artifact-editor/issues/5)。已发布阶段一 `30684e3`、阶段二 `2368b24`、阶段三 `cc30c08`、阶段四 `1fc54a82dbb66348162ffce88d8b8cc2f5e57611`；当前第五阶段以阶段四提交加本次差异验证，最终提交见 Issue。**任务仍进行中**，本记录覆盖后台合同与自动实验，尚无供用户操作的校稿技术 UI。

## 本阶段行为

真实原生点击选择标题/表格 Text 后，Main 从当前草稿取得旧值，在可取消 worker 中重建和验证基线、净 Patch 与完整新候选，再请求隔离 registry 同步核对并修改 Text.data。确认成功才发布新草稿；不写原 HTML。取消另存不写文件；显式另存可独占创建同目录新 HTML，校验完成后在新会话重开。

第二阶段补充编辑目标固定与 Main 未应用输入，第三阶段接可信 renderer IPC，第四阶段验证文档替换和原生 window.close 事件保护，第五阶段组成同一 Main 窗口会话并验证视图挂载回滚及 UI 失效重连。正常 `npm run dev` 和 `npm run preview` 入口仍只读；由 `test:draft` / `test:editor` / `test:workspace` / `test:session` 自动驱动。真实控件/IME/焦点、用户对话框和产品按钮仍未接入，不能把接口或程序触发的关闭事件当作用户完整校稿或 M1/M2 验收。

赋值后只接受唯一的目标 characterData 记录，随后更新登记值；空串保留同一个 Text 对象以便续写。无变化不产生新净 Patch 或草稿 revision，但仍使旧选择 revision 过期。同节点改回基线保留原实体字节。外部即使赋相同值，仍使映射失效。

确认丢失时保留已知候选和待确认候选，拒绝编辑/另存盲目重试；关闭服务也不清除这些对象。当前仅保留内存证据，崩溃持久化与恢复界面仍待 HAE-010，不能宣称可恢复。

另存期间冻结当前候选和命令入口，取消选择器保持原草稿；成功后仍保留原入口基线和未保存变更，不把副本创建误称为原文件已保存。适配器在独占创建后保持同一句柄，写入、sync、回读 SHA-256，前后核对目录链及文件身份、大小、时间和链接数。创建之前失败返回 failed，之后任何异常返回 unknown；不自动删除部分文件、替换文件或证据。

## 执行证据

第二阶段的输入更新只改变 Main 记录，不改变 DOM/Patch/文件。composing=true 阻止应用/取消/另存，非空未应用变更阻止打开保存选择器。应用失败保留包括非法 NUL 在内的原输入供修正；应用成功更新已应用值及输入版本。继续编辑仅清除切换意图；放弃不创建 Patch；“应用并切换”先改原目标，再接受匹配的最新意图。

目标固定期间，浏览器原生选择可以发生变化，编辑器的写入目标仍保持原 Text 身份；每次应用仍校验连接状态、值、映射和 revision。两秒未收到开始/结束确认即撤销 Main 编辑权限，不猜测 renderer 状态。外部 DOM 变化后仍保存晚到的输入，禁止应用；关闭控制器不清空已有输入和候选对象。持久化、界面关闭保护和崩溃恢复仍是后续工作。

第三阶段在真实 contextBridge/IPC 上执行输入和另存：预览页无权限，同源其他窗口无 handler，子框架无公开 API 且其真实 frame 对象被 Main guard 拒绝。测试探针直送伪造路径、额外字段/参数、旧连接或重复 sequence，均拒绝。状态订阅不传 Electron event，旧状态被过滤，回调异常不影响 Main。保存结果区分本次取消与历史成功；拒绝覆盖返回失败，原文不变。主框架导航和实际 renderer 崩溃撤销接口，Main 仍保留未应用文字和候选；选择器期间撤销接口不会启动后续写入。

第四阶段让新文档在旧页旁完成准备；真实 Chromium 已打开而源解析超过深度限制时，新页被销毁，旧页/输入/候选保持。取消离开确认、确认期间的新输入、组合态和忙碌状态均不清空当前文档。原生 window.close() 的重复请求只有一次确认，取消或另存失败不销毁窗口；副本回读正确后才可关闭。创建后注入磁盘故障时，部分文件、草稿和原窗口全部保留，并拒绝继续打开其他文档，等待恢复。

第五阶段通过同一窗口的真实 preload/IPC 完成标题和重复单元格修改、另存及副本重开。新视图附着、设置尺寸、移除旧视图三处注入故障，均在提交前恢复旧页和输入；旧文档命令不会命中新文件，即使输入 revision 碰巧相同。确认期间晚到 IPC 文字使旧决定失效。实际 renderer 崩溃取消未返回的离开确认，Main 重建页面后仍是原文档/输入/候选；旧 token 和迟到放弃决定被拒绝。导航撤销未返回的另存选择器，释放 busy 状态且不写迟到路径。原生 resize 尺寸故障设置 unavailable/cleanupPending，保留文字并阻止继续应用、保存、打开和关闭。
