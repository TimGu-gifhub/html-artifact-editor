# HAE-009 · 方案 B 实时校稿工作台

日期：2026-09-10。状态：Windows 产品开发预览已接通；Issue 保持开放以跟踪真实输入法及维护者验收。基线提交为 `9f8b61f`，实际交付提交以 Git 历史和 [Issue #9](https://github.com/TimGu-gifhub/html-artifact-editor/issues/9) 为准。M2 尚未整体验收。

## 可见行为

- 正常 `npm run dev` / `npm start` 打开产品工作台。使用方案 B，在静态页面点选支持的单个 Text，可信校稿栏中输入，停顿约 250 毫秒自动预览，无需点击应用。
- 组词开始即向 Main 同步保护标志；组词结束后更新。串行 change/Apply 保留最新待发文字，旧文档/token/世代的结果不能修改新绑定。Escape 取消待预览输入，已预览内容通过还原文件原文或 Undo/Redo 恢复。
- 复核列表显示真实原文/新文，可逐条勾选或全选。再次修改某条后清除该条标记。只有全部当前净变更复核且最新源码 Diff 未过期才允许覆盖保存，保存继续先备份、原生替换和回读核验。
- 校稿栏可隐藏或拆成真实独立窗口；浮窗原生关闭表示停靠。主窗口始终拥有同一文档/历史/权限，原生关闭先等待已接受 Save，再排空当前输入窗口。失败或组合态保留输入。
- PDF 从已确认草稿生成，支持 A4/Letter、横向及背景选项。独立查看器显示这次生成的 PDF，导出使用同一份字节；旧文档/旧修订的快照有提示。导出仅创建新 PDF，不写 HTML，不支持修改 PDF 内容、分页版式或注释导出。
- 另存 HTML、恢复记录、当前文件备份及资源诊断控件连接既有 Main 接口。整份备份恢复仍须单独原生确认，不能带着未保存草稿覆盖恢复。

原型人为只开放五处演示文字；产品验证包括原型范围之外的普通正文。实际支持边界保持不变：只编辑可唯一映射且上下文受支持的静态 Text；表单/按钮、脚本生成文字、Canvas、SVG 和歧义结构仍只读。

2026-09-10 核对 [官方模型目录](https://www.kimi.com/code/docs/kimi-code/models.html) 与 [Kimi K3 公告](https://www.kimi.com/news/kimi-k3)。本任务稳定使用 Kimi Code CLI **0.42.0**、完整别名 **`kimi-code/k3`**、实际配置模型 **`k3`**、thinking enabled / high。

Kimi 实际执行初次 UI 实现及后续限定修正，负责 `src/ui/**` 和其新增 UI 行为测试；主代理使用 Codex / GPT-6，负责 contracts、preload、Main 产品装配、平台 PDF 新文件导出、独立测试、文档与审查。同一时间只保留一个写入者，未改动依赖或引入应用内 AI API。原始调用日志、配置、机器路径和截图不提交公开仓库。
