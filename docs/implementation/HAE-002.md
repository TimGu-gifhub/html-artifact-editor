## 交付行为

- `npm run preview` / `preview:interactive` 提供独立验证入口，原生选择器只授予所选 HTML 的父目录。普通 `dev` / `start` 保留内置工具链壳，产品 React 前端未变更；没有 Kimi 前端生成记录或视觉验收声明。
- 每次加载分配独立内存 session、随机 artifact 域和世代，使用 sandbox/contextIsolation/webSecurity、关闭 Node 集成的 WebContentsView。页面没有 Main、文件或保存桥。
- 入口为只读 UTF-8 原始字节快照；CSS、图片、字体与交互模式的本地脚本按请求读取。路径只解码一次，校验根范围、私有目录、资源白名单、路径链、realpath 和打开句柄身份；拒绝链接、别名、读中替换及二次编码。
- 校稿的响应 CSP 禁止页面脚本；交互可运行本地 classic/module/inline JS。原页 CSP 保留并叠加执行。两种模式都不产生文字草稿、Patch 或文件写入。
- 请求层、session offline、CSP、权限、导航和下载事件共同执行离线限制；文档创建钩子额外关闭绕过普通 URL 加载的 WebRTC/WebTransport 和原生文件能力。保护失效会撤销并关闭视图，不静默降级。
- Main 启动确认只接受当前 contents/session/主 frame/源 URL/世代/模式/schema；旧会话、子 frame 与伪造写参数被拒绝。快速切换/关闭取消过期加载，失败保留最后成功预览；会话撤销会阻止在途读取返回字节。

资源白名单、保守兼容限制、大小预算和命令见 [开发说明](../DEVELOPMENT.md)；具体设计见 [架构](../../ARCHITECTURE.md)。本次不新增依赖，锁文件与许可证清单保持一致。

真实 Electron 断言覆盖：

1. 隔离 preload 启动、页面无 Node/文件能力、入口字节原样返回，中文/实体/CSS import/本地 SVG/实际 TTF 加载成功。
2. 校稿拒绝内联、外部、模块、插入 script、SVG/onClick 事件和 javascript 链接。
3. 实际协议拒绝私有目录、其他 HTML、编码路径、ADS、其他 artifact 会话与 POST。
4. 交互模式执行本地 JS/模块、Canvas、Shadow DOM；切换后旧 contents 销毁、URL 失效、存储不继承。
5. 页面 fetch/XHR/WebSocket/EventSource、远程图片/字体、Beacon、worker/data、权限、表单、弹窗与外部协议被阻断；下载事件取消，HTML 文件选择触发 cancel 且 files 为空；资源提示没有连接测试服务器。
6. WebRTC/WebTransport/文件选择器不可用；同步创建的 about:blank 子 realm 无法恢复网络构造器。
7. 使用测试专用攻击 preload 发出真实 IPC：附加 path/offset/nodeId、旧世代、已撤销授权和子 frame 均被拒绝；主/子 frame 请求 `hae:save` 得到没有 handler 的拒绝。
8. 入口原 meta CSP 和字节均保留，仍可禁止交互模式的本地脚本/内联样式；失败打开保留当前视图。
9. 竞争打开只有最新加载可成为当前项目，关闭取消在途加载，旧响应不能回填。
10. 文档保护连接断开时撤销资源并销毁；15 个生成样例/资源/私有哨兵 SHA-256 全部不变，清理完成。

测试输出中的 `No handler registered for 'hae:save'` 是预期负向结果。测试专用 preload 不进入应用或验证入口构建，没有页面测试开关。`test-results/security.json`、三张 `security-*.png`、临时目录与 profile 被 Git 忽略；报告记录基线 commit 和 worktreeDirty，不冒称为已发布版本。

## 修复与边界

新 WebContents 尚未启动 renderer 时，CDP 命令会等待；现先加载可信空白页、安装文档保护，再加载任何用户 HTML。销毁过程中调试连接也会断开，撤销必须幂等，正常关闭不能再次进入原生销毁。两处问题均在实际运行中复现并修复。

发布前复查遇到原生视图刚显示/调整大小时的暂态 `UnknownVizError`。截图辅助仅对此错误进行有上限的等待重试，仍要求取得真实非空图像；其他错误或超过上限继续使检查失败，不跳过截图或使用旧产物。

`sendBeacon` 的 true 只表示可排队，因此通过 CSP 违例和测试服务器零连接确认拒绝，不把返回值当作发送成功。URL 过滤参考 [Electron WebRequest](https://www.electronjs.org/docs/latest/api/web-request)，文档创建/文件选择器保护参考 [CDP Page](https://chromedevtools.github.io/devtools-protocol/tot/Page/)；没有关闭 CSP、沙箱或证书验证。

初期明确拒绝 frame、worker、data/blob、媒体、eval、非白名单扩展名和所有链接路径；依赖这些能力的 HTML 不保证完整显示。文件身份复核不是任意文件系统上的内核原子授权；同权限敌对本地进程、网络盘、云同步和更多竞态仍需后续审计。没有写入功能，也没有把现有路径检查当成保存事务的保证。
