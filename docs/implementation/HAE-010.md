# HAE-010 实施记录：保存准备

日期：2026-09-09。对应 [Issue #10](https://github.com/TimGu-gifhub/html-artifact-editor/issues/10)。本次交付第一阶段的文件基线检查、私有锁、备份/候选/准备记录与重启只读检查；正常应用尚未接线，没有覆盖或恢复写盘能力。HAE-010 与 M2 保持未完成。

## 行为与合同

源文件打开时固定字节、目录链、文件身份及纳秒时间戳，准备前重复核验。Main 私有存储使用同一目录的全局独占锁，备份和候选通过完整句柄写入、sync、独立回读/hash 与前后身份检查；准备和取消记录均独占创建。失败保留部分证据；正常取消仅释放本调用仍拥有的锁。

重启 scan 发现完整/部分记录与遗留锁；inspect 校验 schema 和字节关联，再比较 Main 重新授权的目标。旧基线、候选已在磁盘、外部冲突和不可读状态分开，不自动覆写或解除遗留锁。记录不含绝对路径，不从记录中恢复路径权限。细节与预算见 [保存准备合同](../SAVE_PREPARATION.md)。

没有产品组件、样式、恢复界面或 Kimi 前端变更。候选语义仍由已有源码映射/Patch 核心负责；本阶段只验证和保存其冻结字节。所有文件样例自行创建，未使用业务资料或 GitHub CI。

## 已执行证据

Windows 11 x64 / Windows_NT 10.0.26200；开发 Node 24.14.1 / npm 11.19.1。新增 [10 项存储测试](../../tests/unit/save-preparation.test.mjs) 在开发 Node 和 Electron 44.2.0 内嵌 Node 24.20.0 下均执行通过。内嵌运行使用仅限测试子进程的 Node 模式，无窗口/页面，不改变正常应用的沙箱和启动策略。

| 检查 | 已观察到的结果 |
| --- | --- |
| 实际核心候选 | 通过源码索引/Patch 引擎修改中文/Emoji/实体标题；备份和候选分别与完整独立 Buffer 期望一致，BOM/CRLF、注释、脚本和原 HTML 不变 |
| 基线/候选拒绝 | 外部内容、同文新身份、硬链接、删除、目录替换拒绝；错误基线/hash/超限和无变化均不创建锁或记录；Windows 原生大小写别名键一致 |
| 第二实例 | 独立 OS 子进程在锁存在时拒绝准备；原持有者正常取消后下一子进程可准备 |
| 写入失败 | intent/backup/candidate/prepared 七个边界注入 ENOSPC 异常，源 HTML 零写入，部分证据保留；不是实际塞满磁盘 |
| 损坏与晚到外部写入 | 备份/候选改坏、准备记录完成时源被外部改写均拒绝 prepared；后者报告 FILE_CHANGED，保留外部结果 |
| 重新检查 | 新建 store 实例 scan/inspect；无目标时不读 HTML，错误目标、内容冲突、候选内容、文件不可读、新 inode/时间戳及损坏 schema/seal/字节均独立核对 |
| 强制终止 | 实际子进程在 lock-created、intent-synced、backup-created、backup-synced、candidate-synced、prepared-synced 六个节点被 SIGKILL，确认该退出信号；重启保留原 HTML 和遗留锁，禁止盲目重试 |
| 所有权与预算 | 锁被改写时取消不删除别人的锁；达到同目标 20 项记录后拒绝新准备，不自动删除任何备份 |

`npm run check` 已通过：四套 strict 类型、59 源文件边界、151 单元、八目标构建；6 冒烟 / 10 安全 / 10 映射 / 4 Patch / 20 草稿 / 9 IPC / 7 文档 / 10 会话 / 8 目录组，另有内嵌 Node 的 10 项存储测试及 62 包许可证。之后加固规范路径键，再通过类型、151 单元与内嵌 Node 存储定向复测；文档/差异门槛和最终发布 commit 见 Issue 评论。
