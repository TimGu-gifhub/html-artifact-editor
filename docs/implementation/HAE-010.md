# HAE-010 实施记录：保存准备与 Windows 提交

日期：2026-09-09。对应 [Issue #10](https://github.com/TimGu-gifhub/html-artifact-editor/issues/10)。第一阶段交付准备证据；第二阶段增加 Main 显式 Windows 提交、结果回读和提交/未知判断。正常应用尚未接线，没有恢复写盘能力。HAE-010 与 M2 保持未完成。以下第一阶段记录保留当时范围与计数，第二阶段见文末。

## 行为与合同

源文件打开时固定字节、目录链、文件身份及纳秒时间戳，准备前重复核验。Main 私有存储使用同一目录的全局独占锁，备份和候选通过完整句柄写入、sync、独立回读/hash 与前后身份检查；准备和取消记录均独占创建。失败保留部分证据；正常取消仅释放本调用仍拥有的锁。

重启 scan 发现完整/部分记录与遗留锁；inspect 校验 schema 和字节关联，再比较 Main 重新授权的目标。旧基线、候选已在磁盘、外部冲突和不可读状态分开，不自动覆写或解除遗留锁。记录不含绝对路径，不从记录中恢复路径权限。细节与预算见 [保存准备合同](../SAVE_PREPARATION.md)。

没有产品组件、样式、恢复界面或 Kimi 前端变更。候选语义仍由已有源码映射/Patch 核心负责；本阶段只验证和保存其冻结字节。所有文件样例自行创建，未使用业务资料或 GitHub CI。

## 第二阶段：实际 Windows 替换与提交记录

基线为 `3405d9e227d3dd40c05c05e696751c587922d526`。增加 [Windows 适配器](../../src/platform/windows-replacement.ts)、[有限协议 C# 助手](../../src/platform/windows/ReplaceHelper.cs) 与 Main commit：私有证据再次校验 → 同目录独占候选 → 目录/源句柄检查 → replacing 日志 → ReplaceFileW → 新目标与移走原件复核 → Main 独立回读 → committed 日志 → 按持有句柄清理旧文件副本。原始私有备份和候选不删除。

重复 commit 共用同一结果；启动后的失败/未知不允许 cancel 或盲目重试。明确提交后清理失败仍报告 committed + cleanupPending。重启把 replacing/committed、候选仅在磁盘、当前版本与已提交版本不同分别处理；记录不携带目标绝对路径或可复用写权限。完整顺序、资源上限与残余竞态见 [保存事务合同](../SAVE_PREPARATION.md)。

Windows 使用本机 .NET Framework C# 编译器生成 helper，不下载新的运行依赖、不提交可执行文件。ReplaceFileW 不忽略 ACL 合并错误。对旧式 ACL 的继承位转换采用明确记录的兼容恢复，再复核 ACE 字节和控制位；权限不足则拒绝或保留未知结果。该路径使用微软标记 obsolete 的 SetFileSecurityW，仅用于还原原 DACL，后续平台替换方案需保留这一兼容性证据。没有产品前端文件或 Kimi UI 变更。

### 第二阶段执行证据

新增 [11 项保存事务测试](../../tests/unit/save-commit.test.mjs)，仅操作自制 NTFS 文件；实际主机仍为 Windows 11 x64 / 10.0.26200，开发 Node 24.14.1，Electron 44.2.0 / 内嵌 Node 24.20.0。

| 检查 | 观察到的行为 |
| --- | --- |
| 正常替换与再保存 | 使用纯核心生成的中文/emoji/实体补丁；整份独立期望 Buffer 匹配，BOM/CRLF/注释/脚本保留；重复请求只做一次，新事务可重新取得锁 |
| 创建时间、ACL、数据流 | 旧式与受保护 DACL 的独立指纹一致，保留 Zone.Identifier 和中文命名流；文件 ID 变为候选 ID，正常清理不留项目 sidecar |
| 取消/缺少适配器 | 原 HTML 零写入，项目目录不出现临时文件 |
| 外部冲突/证据损坏 | 内容、同文新 inode、目录替换、backup/candidate/锁改坏均拒绝；预占候选或备份名称不被覆盖 |
| 最后复核 | replacing 日志同步时替换临时文件/备份预留名，或添加候选数据流；原文件不变，外部 sidecar 字节保留 |
| 实际 Windows 权限与占用 | readonly 属性、DACL 禁止 WriteData、独立 C# 进程持有不共享删除的句柄均拒绝；不是模拟权限异常 |
| 文件守卫 | 助手 ready 与 replaced 两处，外部 writeFile 和祖先目录 rename 实际失败；等待 Main 日志期间保持结果守卫 |
| 替换前故障 | 七处临时写入/同步、ready、replacing 创建/同步故障，原 HTML 保持原字节；ENOSPC 为注入，不是真实塞满磁盘 |
| 替换后故障 | 五处结果确认或 committed 写入/同步边界异常，返回 unknown，保留旧副本和私有证据、锁；重复调用不再次覆盖 |
| 清理故障 | 已核验 committed 后私有锁清理失败，保持新 HTML，明确 cleanupPending，并阻止下一请求 |
| 真实强杀 | 独立 Main 进程在 native-ready、replacing-synced、native-replaced、committed-synced 四处被 SIGKILL，确认信号并检查助手释放写守卫；重启识别旧基线、候选在盘或完整提交记录，锁不自动解除 |
| journal 拒绝 | 错误新 hash、无效身份、额外字段和 cancelled 与 replacing 并存均为 invalid；外部重写相同候选字节也不冒充原提交版本 |
