## 第一阶段交付

从已验证的净 Patch 导出有限逻辑 Text 意图，保留原始基线；恢复时重新解析、核验来源，再生成新字节位置与完整候选。检查点由不可覆盖的 record/baseline/complete 三文件组成；每步句柄写入、sync、回读，之前的完整点不被失败覆盖。相同修订可确认重试，旧修订拒绝，清理警告与持久化结果分别报告。完整合同见 [草稿检查点](../DRAFT_CHECKPOINTS.md)。

草稿与保存使用同一私有目录、active.lock、每目标合计 20 份记录和总计 200 MiB 配额。两类扫描只列各自记录；不自动清理、解除遗留锁或选取旧草稿回放。重启恢复需 Main 重新授权文件并验证完整身份/hash；匹配实际 committed 版本的检查点拒绝重复应用，只有候选字节相同则保留未确认状态。

本阶段没有产品组件或样式，没有 Kimi UI 实施，也没有 GitHub CI。所有源文件、私有记录和进程故障现场均自制并位于忽略目录；公开仓库只含代码、测试和说明。
