## 已解决的工具链问题

- Electron 44 使用显式二进制安装步骤；将其纳入 postinstall，避免依赖安装成功却缺少运行时。
- TypeScript 6 的严格副作用导入检查需要本地 CSS 模块声明；不为此关闭检查。
- 关闭整个 JavaScript 引擎会使 Preview preload 无法初始化；验证壳改由严格 CSP 禁止页面脚本，保留引擎供隔离 preload 使用。沙箱、webSecurity、contextIsolation 未降低。真实用户 HTML 的原 CSP、noscript 解析语义和脚本入口仍待 HAE-002/003 验证。
- 原生视图销毁和最后窗口退出具有异步生命周期；测试等待 destroyed，并在独立测试主进程中阻止提前退出以完成报告写入。父进程要求新的 passed 报告和成功退出码，避免假阳性。
- 普通入口保持主窗口引用，并对创建过程防重入；正常启动按 package.json 入口启动，窗口可见，工具进程不将 GUI 设为隐藏。
- 本地继承 PATH 过长导致 npm 的 cmd 子进程无法找工具；本次仅在验证进程中使用必要工具目录，未修改系统 PATH。
