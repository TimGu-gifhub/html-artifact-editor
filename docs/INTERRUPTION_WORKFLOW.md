# 产品中断检查

日期：2026-09-10；HAE-010 / HAE-011。Windows 工作台的“更多操作 → 检查上次中断”接入既有 [保存中断处置](SAVE_RECOVERY.md) 和 [检查点清理恢复](COMPACTION_RECOVERY.md)。检查需要在重启后、打开文档前进行；不会自动关闭当前文档、重放草稿或写入 HTML。

保存准备尚未完成时，若意图完整、当前原文件严格匹配且残留文件符合写入顺序，也可通过同一选择/确认流程明确放弃该次准备。全部原证据继续保留，记录 v2 决定，不生成 prepared 或 committed 日志。精确条件见 [准备中断处置](INCOMPLETE_SAVE_RECOVERY.md)。

## 操作与结果

用户先选择原 HTML，Main 固定其当前完整版本并核验记录，再用单独的原生对话框确认。确认默认选“取消”。文件选择、准备或确认取消不写文件和记录；重新检查必须重新选择并核验，不能复用旧确认。

| 核验结果 | 确认后的行为 |
| --- | --- |
| 保存前版本仍匹配 | 保留当前文件，记录这次决定并移除准确旧锁；之后可通过“恢复草稿记录”另行核验可用草稿 |
| 已提交证据匹配当前文件 | 保留已核验的当前文件，完成中断处置；既有 v2 历史恢复重新建立干净基线，不重复回放 |
| 候选内容在磁盘，但没有已验证提交证据 | 只确认保留当前文件，不改记旧保存成功，不回放旧历史 |
| 当前文件与记录冲突 | 保留当前文件及旧证据，不把旧草稿直接写到当前版本 |
| 完整检查点清理记录 | 继续核验过的旧点清理，保留最新两个完整点、其他会话及备份；不代表新修改已持久化或 HTML 已保存 |

对话框显示 Main 的 checking / reviewing / resolving 状态和实际结果。`WorkspaceResult.ok` 只表示命令处理结束；界面不能据此关闭对话框或报告保存成功。没有可处理的锁返回 unavailable，不表示所有历史记录都健康。准备失败保留原记录；unknown 或完成后的收尾警告保留窗口与证据，禁止直接重试和后续文档操作。

## 权限与生命周期

[唯一命令](../src/contracts/desktop.ts) 为 `inspect-interruption` 加准确的工作区 stateRevision，只接受主窗口。renderer 不提供路径、私有字节、锁、助手、事务 ID、提交决定或 force。摘要中的 reviewId 不能通过 IPC 变成确认权限；[原生决定](../src/contracts/interruption.ts) 必须包含准确的两个自身字段，并匹配这次审查及操作种类。

[产品编排](../src/main/product/interruption.ts) 使用当前持久化实例的固定 userData/workspace-records；分类锁只用来选择既有准备器，不授权清理。源文件经过新授权、受限读取和完整版本固定；准备器再次核验 profile、目录占用、完整事务/清理证据、当前文件和已有处置记录。保存处置继续使用原有 Windows 只读 guard；没有新的 HTML 写入或通用解锁路径。

界面先同步取得共享操作门禁与对话框 latch，排空实际输入窗口，重核可空文档身份、组词和工作区状态，再发送最新修订。关闭/重开或卸载后的迟到错误只属于原对话框。检查期间阻止竞争操作和快捷键；原生 Preview 沿用模态隐藏机制。键盘关闭回到稳定的“更多操作”按钮。

Main 在检查进行中或结果待审查时拒绝文档、保存、恢复、PDF 和面板操作，仅允许布局和已接受输入排空的回执。已开始关闭时拒绝新的检查。原生关闭先等待这一次检查结果，再排空输入；未知结果或警告拒绝正常关闭。运行实例清理还会等待所有已接受的 bridge 命令及此控制器；未确认收尾时保留进程内实例占用和 profile 所有权。

确认前界面丢失，使旧决定失效；等待原生回调结束后取消准备。确认提交一旦开始，界面丢失不能撤销事务或触发重试，Main 等待同一结果并向重建的可信界面提供状态。启动、打开说明、关闭说明和读取状态都不会隐式处理旧记录。

## 验证与边界

`npm run test:product-interruption` 使用真实产品、Electron 窗口、preload、Worker、原生文件保护与进程强杀；通过实际文字输入、复核保存、菜单和恢复按钮运行。父进程独立核对完整 HTML、BOM/CRLF、实体、中文/emoji、脚本、CSS 和原有证据。Main 回调提供测试用文件选择与独立决定；这不替代真实原生对话框或输入法人工操作。运行证据见 [HAE-010 第七、八阶段](implementation/HAE-010.md)。

本入口只处理准备器能够完整核验的记录。缺少完整意图或无法验证写入顺序的准备中断、空锁、部分/损坏/冲突处置记录、结束事务锁、活动未知会话的解除冻结，以及跨会话/备份/sidecar 清理仍未完成。维护者报告校稿、Windows 10、真实 IME/对话框、DPI/读屏、磁盘满与断电验收保持待办；M2 不因此完成。
