# 风险与降级安排

以下是设计风险登记，概率与影响为规划判断，不是统计结果。HAE-002/003 已执行部分权限和静态映射实验，范围见对应交付记录；保存、性能与完整产品验收仍待执行。

| ID | 风险 | 影响 | 先做的验证 | 失败处理 / 对应任务 |
| --- | --- | --- | --- | --- |
| R-01 | Chromium DOM 与源码不一一对应 | 误改其他位置，最高优先级 | 重复文字、纠错树、实体、嵌套文本的正反例 | 只开放可证明节点；HAE-003 |
| R-02 | JS 接管 DOM 或内容来自数据层 | 保存看似成功但重载丢失 | 同文字重建、框架重渲染 | 首版 JS 预览只读；HAE-002/003 |
| R-03 | UTF-16 下标当成 UTF-8 字节 | 中文/Emoji 后错位 | BOM、Unicode、CRLF 独立字节比对 | 阻断发布；HAE-004 |
| R-04 | 外部并发改写和文件系统竞态 | 覆盖用户其他改动 | 保存各节点注入外部写入 | 拒绝冲突，另存；记录残余窗口；HAE-010 |
| R-05 | 替换/备份/掉电恢复失败 | 源文件丢失或无法判定 | 权限、锁、磁盘、强制终止 | 不开放覆盖保存，先修事务；HAE-010 |
| R-06 | 恶意 HTML 经预览越权 | 泄露/破坏本地文件 | IPC、路径、导航、网络负向测试 | 阻断运行能力和发布；HAE-002/013 |
| R-07 | 静态校稿关闭脚本造成效果变化 | 用户误解“所见即所得” | 同一报告静态/交互视图比较 | 显示模式与只读原因，不承诺动态编辑；HAE-007 |
| R-08 | WebContentsView 原生层覆盖浮层 | 编辑控件不可点、IME 错位 | DPI、窗口/焦点/缩放组合 | 可信侧栏输入为 MVP 默认；HAE-007/009/014 |
| R-09 | 离线 HTML 依赖 CDN/API | 字体、图表缺失 | 拦截日志和资源诊断 | 明示缺失，不自动联网/下载；HAE-008 |
| R-10 | 无 Mac 实机或签名条件 | 双平台交付延迟 | M1 开始确认可用设备与证据 | Windows 可以继续，Mac 保持未验收；HAE-006/015 |
| R-11 | OS 最低版本与运行时更新冲突 | 失去声明的支持范围 | 每次固定/升级运行时复核官方范围 | 更新支持矩阵，不冻结失去安全维护的版本；HAE-001/017 |
| R-12 | AI 一次修改范围过大 | 引入越界功能与难复核变更 | 每 Issue 的允许路径和验收对照 | 小提交、独立复核，不以生成量衡量进度 |
| R-13 | 备份和草稿含用户内容 | 隐私暴露、磁盘占用 | 私有存储隔离、清理和日志检查 | 不提交数据，提供清理；HAE-010/011 |
| R-14 | 数据量超预算 | 卡死、无响应、内存增长 | 文件/DOM 上限和超时实验 | 只读/拒绝超限，保留可信 UI 恢复能力；HAE-013 |
| R-15 | 第三方样例或资产许可不清 | 开源分发受限 | 来源和许可证记录 | 自制样例或替换依赖，保留声明；HAE-013/015 |

## 决策门槛

R-01/R-03/R-05/R-06 未解决时，不开放源文件覆盖保存。可以交付明确标记的受限实验程序，但不可宣称可用 MVP。

R-10 不应被包装成“Windows 已跑通所以 Mac 没问题”；双平台代码共用与双平台验收是不同结论。签名凭据/付费项目由维护者提供，计划本身不购买或开通服务。
